# Shutterfly POC Prototypes

This repo contains standalone HTML proof-of-concept files for the Shutterfly web, Android, and iOS experiences.

## Run Locally

Install dependencies once:

```bash
npm install
```

Start the local server:

```bash
npm run dev
```

Open the prototype hub:

```text
http://localhost:5173/
```

The hub links to every HTML prototype and the Lighthouse report HTML files.
